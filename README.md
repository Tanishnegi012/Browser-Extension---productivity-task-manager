# 🚀 Extensify BE

**Extensify BE** is a modern productivity-focused browser extension that replaces the default new tab page with a personalized dashboard. It helps users manage daily tasks, stay organized, and remain motivated through inspiring quotes and a clean user interface.

---

## 📖 Overview

Extensify BE transforms every browser new tab into a productive workspace. Instead of displaying a blank or standard browser page, the extension provides users with a task management interface and motivational content to improve focus and productivity.

The project is designed with simplicity, performance, and user experience in mind, making it suitable for students, professionals, and everyday users.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/extensify-be.git
cd extensify-be
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm start
```

Application will be available at:

```text
http://localhost:3000
```

---

## 🔨 Build for Production

Generate an optimized production build:

```bash
npm run build
```

The production files will be created inside the `build` folder.

---

## 🧩 Load Extension in Chrome

1. Open Chrome Browser.
2. Navigate to `chrome://extensions`.
3. Enable **Developer Mode**.
4. Click **Load Unpacked**.
5. Select the generated `build` folder.
6. Open a new tab to use Extensify BE.
